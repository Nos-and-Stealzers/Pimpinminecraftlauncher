The Windows build isn’t code-signed yet, so SmartScreen may warn you the first time. Choose More info, then Run anyway. The portable and .deb copies don’t update themselves; download a new copy when there’s a new version. Want an AppImage or an older version? Browse every release on GitHub.

What’s inside

  • Just press Play

    It downloads the game, libraries, assets and the right Java for each version. You don’t install Java yourself.

  • Instances for everything

    Every instance has its own version, loader (Vanilla, Fabric or Quilt), mods, worlds, memory and Java settings. From 1.8.9 up to the newest releases.

  • Mods, shaders and packs

    Browse the Modrinth library and install in one click, dependencies included. Modpacks become ready-to-play instances.

  • Pimpin Client

    Our own Fabric and Quilt mod: HUD, minimap, big map, waypoints, zoom, an FPS booster and an in-game mod menu, with a movable HUD layout.

  • Our own packs and shaders

    Pimpin Performance and Pimpin Pretty resource packs, plus Shaders Lite and Ultra. Pick Max FPS, Balanced or Max Pretty and everything is set up for you.

  • Local servers

    Start a Paper, Purpur or Vanilla server, add plugins, use the console, back up the world and join with one click.

  • Safe with your stuff

    Sign in with Microsoft, with tokens kept in your system keychain. World backups make a safety copy before any restore.

  • The small things

    Dark, Midnight and Light themes, a wardrobe with 3D previews, a screenshot manager, a crash helper that explains what went wrong, and Ctrl+K to find anything.

Forge and NeoForge aren’t supported yet. Fabric and Quilt are.
